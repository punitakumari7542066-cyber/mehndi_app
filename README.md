🚀 Build Flutter APKs without installing Flutter

No Android Studio. No SDK setup. No headaches.

👉 Just push your code → get a downloadable APK.

---

⚡ What is this?

This is a plug-and-play GitHub template that automatically builds your Flutter APK using GitHub Actions.

Perfect for:

- Beginners who don’t want heavy setup
- Developers with low-end PCs
- Hackathons & quick demos
- Testing Flutter builds instantly

---

🛠 How it works

1. Click "Use this template"
2. Upload or replace with your Flutter project
3. Push your code
4. Go to the Actions tab
5. Download your APK from Artifacts

---

📦 Features

- ✅ No local setup required
- ✅ Automatic APK build on push
- ✅ Free using GitHub Actions
- ✅ Works on any device (even low-end laptops)
- ✅ Beginner-friendly

---

🚀 Getting Started

1. Use this template

Click the "Use this template" button at the top of this repo.

---

2. Add your Flutter project

Replace the existing project files with your own Flutter app.

---

3. Push your code

git add .
git commit -m "Add my Flutter app"
git push

---

4. Download your APK

- Go to the Actions tab
- Open the latest workflow run
- Scroll down to Artifacts
- Download your APK 🎉

---

⚙️ Workflow Overview

The GitHub Action automatically:

- Sets up Java (required for Android build)
- Installs Flutter
- Runs "flutter pub get"
- Builds release APK
- Uploads APK as downloadable artifact
